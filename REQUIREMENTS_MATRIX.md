## Как читать колонку проверки

`Vn/ГРУППА` — планируемая проверка группы в спринте n, подробно описанная в соответствующем разделе плана. Это **ссылка на будущую проверку, не результат теста**. Для строки TEST дополнительно обязательна точная процедура и критерий из самой строки. Для условного требования проверяется и включение условия, и поведение при нём; отсутствие опционального флага не закрывает зависимый Must автоматически.

| Группа | Вид доказательств |
| :-- | :-- |
| STR | Проверка структуры/Git/упаковки, воспроизводимая установка и исполнение документированных примеров; для наследования — регрессия предыдущих STR. |
| CLI | Вызовы CLI через subprocess: корректные и конфликтующие параметры, stdout/stderr, формат и коды возврата; соответствующий функциональный результат. |
| CRY | KAT/эталон, граничные длины, корректность padding/потоковых режимов, обзор использования только разрешённого AES-примитива. |
| IO | Временные файлы/бинарные данные, точный контейнер, короткий/повреждённый ввод, пути Windows, ошибки доступа и сохранность результата. |
| IV / KEY / RNG | Длины/источник/форматы/интеграция, уникальность по заданному числу выборок, вывод ключа и отсутствие его в файле, имитация отказа RNG. |
| HASH | Официальные KAT, пустой и большой ввод, разбиение потока, независимая совместимость и проверка ограниченного потребления памяти. |
| MAC | RFC-векторы, ключи разных размеров, пустые/большие потоки, обнаружение подмены и безопасное сравнение. |
| AEAD | GCM KAT, GF/GHASH/nonce, независимые ключи композиции, подмена всех аутентифицируемых полей, отсутствие plaintext до проверки. |
| KDF | Согласованные SHA256 KAT (C19), сравнение с независимой реализацией, iterations/length, контексты и детерминизм. |
| TEST | Фактический запуск указанного теста/эксперимента, зафиксированные параметры и отчёт; включая внешние инструменты и STS. |
| DOC / UG | Полнота по подпунктам, соответствие публичному API, исполнение примеров и установка в заявленных средах. |
| QA | Документированный обзор безопасности, отчёты проверок, версии зависимостей, наличие и содержание обязательных документов. |
